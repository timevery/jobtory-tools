# 루미의 하늘길

5개 세계, 20개 스테이지로 구성된 오리지널 횡스크롤 플랫폼 게임입니다.

## 실행

`index.html`을 다운로드해 Chrome 또는 Edge에서 열면 됩니다. 별도 설치나 빌드가 필요하지 않습니다. HTML 안에 스타일과 게임 코드가 포함되어 있습니다.

GitHub Pages에서 저장소 루트를 게시하는 경우 `/jobtory-tools/lumi-sky-trail/` 경로로 접근할 수 있습니다.

## 조작

- 방향키 또는 A/D: 이동
- Space, 위쪽 방향키 또는 W: 점프 (길게 누르면 높게 점프)
- Shift: 달리기
- P 또는 Esc: 일시정지
- R: 현재 스테이지 다시 시작
- 터치 화면: 화면의 이동·달리기·점프 버튼

별 조각을 모으고 적의 머리를 밟으며 별문까지 이동하세요. 매 네 번째 스테이지에서는 수호자를 쓰러뜨려야 출구가 열립니다. 별 등불은 현재 플레이의 재시작 지점이며, 완료한 단계와 마지막 선택 단계는 브라우저에 자동 저장됩니다. 모든 스테이지를 선택 화면에서 바로 플레이할 수 있습니다.

캐릭터, 지형, 그래픽 및 효과음은 이 게임용으로 제작했습니다.
